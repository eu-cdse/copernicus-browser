# Copernicus Browser — Dataset and layer ids: index

Every `datasetId` and `layerId` that can be used in a Browser link in the default theme (`themeId=DEFAULT-THEME`). Use these ids exactly as written (they are case-sensitive) and never invent one: an unknown `datasetId` makes the Browser show "Selected dataset does not exist!" and silently switch to Sentinel-2 L2A. See deep-linking.txt for the other parameters.

This index is generated by `npm run generate-datasets` from the app's own configuration. Do not edit it by hand.

Layer ids can differ between themes. The ids in these files are the ones for the default theme.

164 datasets in 21 files. Fetch only the file for the data you need. The complete list in one file, which some tools cannot read in full, is [datasets.txt](https://browser.dataspace.copernicus.eu/datasets.txt).

Some CLMS products exist in several consolidation stages (_RT0, _RT1, _RT2, ...) with the same layers. Only one stage is listed per product; the others are named on it as "Also available as". To link to another stage, use that id for `datasetId`, `clmsSelectedPath` and `clmsSelectedCollection`.

## Do not use these ids

These ids look plausible but do not exist.

- `S1_AWS_IW_VVVH`: use `S1_CDAS_IW_VVVH` instead (there is no AWS Sentinel-1 dataset)
- `S1_AWS_*`: use `S1_CDAS_*` instead (use the S1_CDAS_* ids listed below)
- `LOTL1_CDAS`: use `CDAS_L8_L9_LOTL1` instead (Landsat 8-9 Level-1)
- `LANDSAT_8_9_CDAS`: use `CDAS_L8_L9_LOTL1` instead (Landsat 8-9 Level-1)
- `MODIS_CDAS`: no replacement (no MODIS dataset exists in the Browser)
- `S2_WORLDCOVER_ANNUAL_CDAS`: use `65d4af89-5ce5-468e-bbbe-8a2fd9efaccc` instead (WorldCover annual cloudless mosaic)
- `ESA_WORLDCOVER_CDAS`: use `65d4af89-5ce5-468e-bbbe-8a2fd9efaccc` instead (WorldCover annual cloudless mosaic)
- `CCM_VHR_OPTICAL_PLEIADES`: no replacement (Contributing Missions VHR ids are CCM_VHR_IMAGE_<year>)

- [Landsat](https://browser.dataspace.copernicus.eu/datasets/landsat.txt): Landsat 8-9 Level-1 (1 dataset)

- [Mosaics](https://browser.dataspace.copernicus.eu/datasets/mosaics.txt): Sentinel-1 (IW and DH), Sentinel-2 quarterly, WorldCover and Landsat mosaics (5 datasets)

- [CLMS Bio-geophysical Parameters: Soil Moisture](https://browser.dataspace.copernicus.eu/datasets/clms-bio-soil-moisture.txt): Surface soil moisture and soil water index (7 datasets)
- [CLMS Bio-geophysical Parameters: Temperature and Reflectance](https://browser.dataspace.copernicus.eu/datasets/clms-bio-temperature-reflectance.txt): Land surface temperature and reflectance (11 datasets)
- [CLMS Bio-geophysical Parameters: Vegetation, productivity](https://browser.dataspace.copernicus.eu/datasets/clms-bio-vegetation-productivity.txt): Dry and gross dry matter productivity (DMP, GDMP) and net and gross primary production (NPP, GPP) (10 datasets)

- [CLMS Land Cover and Land Use in Priority Areas](https://browser.dataspace.copernicus.eu/datasets/clms-priority-areas.txt): Urban Atlas and Protected Areas (6 datasets)

- [CLMS Land Cover and Land Use Mapping: Tree Cover and Forests](https://browser.dataspace.copernicus.eu/datasets/clms-lcm-tree-cover-forests.txt): Tree cover density, forest types, coniferous and broadleaved cover (10 datasets)
