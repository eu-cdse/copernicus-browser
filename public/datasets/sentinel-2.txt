# Copernicus Browser — Dataset and layer ids: Sentinel-2

Every `datasetId` and `layerId` that can be used in a Browser link in the default theme (`themeId=DEFAULT-THEME`). Use these ids exactly as written (they are case-sensitive) and never invent one: an unknown `datasetId` makes the Browser show "Selected dataset does not exist!" and silently switch to Sentinel-2 L2A. See deep-linking.txt for the other parameters.

This is one part of the dataset catalogue. The other groups are listed in [index.txt](https://browser.dataspace.copernicus.eu/datasets/index.txt). Generated by `npm run generate-datasets`; do not edit it by hand.

The example links use a fixed placeholder position (zoom 11 near Lake Maggiore). Replace `lat`, `lng` and `zoom` with the place the user asked for: a dataset with only regional coverage finds no image at the placeholder.

Some CLMS products exist in several consolidation stages (_RT0, _RT1, _RT2, ...) with the same layers. Only one stage is listed per product; the others are named on it as "Also available as". To link to another stage, use that id for `datasetId`, `clmsSelectedPath` and `clmsSelectedCollection`.

## Datasets

2 datasets.

### S2_L1C_CDAS

Name: Sentinel-2 L1C

Layers:
- `1_TRUE_COLOR`: True color
- `2_FALSE_COLOR`: False color
- `2_TONEMAPPED_NATURAL_COLOR`: Highlight Optimized Natural Color
- `3-WILDFIRES`: Wildfires
- `3_NDVI`: NDVI
- `4-FALSE-COLOR-URBAN`: False color (urban)
- `5-MOISTURE-INDEX1`: Moisture index
- `6-SWIR`: SWIR
- `7-NDWI`: NDWI
- `8-NDSI`: NDSI

Example:

    https://browser.dataspace.copernicus.eu/?zoom=11&lat=45.35625&lng=8.45879&themeId=DEFAULT-THEME&datasetId=S2_L1C_CDAS&layerId=1_TRUE_COLOR&date=latest
